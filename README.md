# GESP Frontend

Frontend de la plataforma **GESP**, desarrollada con **React + JavaScript + Vite**.

## Descripción

GESP es una plataforma orientada al aprendizaje de programación funcional en Haskell. Permite a los estudiantes escribir código, visualizar explicaciones guiadas, consultar recursos de apoyo y realizar un seguimiento de su progreso.

Este repositorio contiene únicamente el **frontend** de la aplicación.

## Tecnologías utilizadas

- React
- JavaScript
- Vite
- React Router DOM
- CSS

## Instalación

Clona el repositorio:

```bash
git clone https://github.com/Dayana200505/GESP_IHC.git
```

Ingresa al proyecto:

```bash
cd gesp
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```



## Funcionalidades

- Editor de código
- Explicación guiada
- Gestión de recursos
- Seguimiento del progreso
- Perfil de usuario
- Inicio de sesión y registro
